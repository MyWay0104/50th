# DESIGN-SAMPLE

## 문제 분석

새 topic 생성 테스트용 샘플 디자인 문서다. 실제 작업에서는 사용자가 `getdesign.md` 웹페이지에서 다운로드한 `DESIGN-회사이름.md` 파일을 이 폴더에 넣는다.

## 설계

- 톤: 실무적, 명료함, 과장 없는 전문성
- 색상: 짙은 남색, 흰색, 선명한 파란색 포인트
- 폰트: Paperlogy 우선
- 레이아웃: 넓은 여백, 강한 제목 위계, 3개 이하 핵심 포인트

## 구현

16:9 deck은 발표자가 말할 여지를 남기고, card-news는 저장 가능한 문장 중심으로 구성한다.

## 코드

이미지 asset이 없는 경우 CSS 기반 면 분할과 텍스트 위계로 먼저 구성한다.

## 테스트 방법

overview에서 텍스트가 카드 또는 슬라이드 영역을 넘지 않는지 확인한다.

## 향후 개선사항

실제 회사별 디자인 문서로 교체한다.
