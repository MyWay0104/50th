# 강사 진행표 (한 장) — AI Agent Guide 하루 과정

이 문서는 **강사만 보는 진행 메모**다. 덱의 화면과 발표자 노트에는 시각과 분을 쓰지 않으므로(수강생에게 시간 압박을 주지 않기 위해), 당일 판단에 필요한 어림값을 여기에만 모았다. 근거는 `docs/edu-storyboard-v1-2026-09-18.md`의 「시간 예산」 절이다.

> 모든 분 수는 실습 코드를 보지 못하고 단계 수로 어림한 값이다. 첫 회차를 마친 뒤 "실제" 칸을 채워 다음 회차에 고쳐 쓴다.

## 2. 점검 지점 세 곳 (시계를 보는 순간)

| 지점 | 언제 | 본다 | 넘겼으면 |
|---|---|---|---|
| ① | 전환 장면 "책 → 손발"(T02)이 끝났을 때 | 오전에 쓸 시간의 **절반**을 넘겼는가 | 사다리 3단 중 "실습 04b 소단계 4(사내 데이터 직접 조회)를 강사 시연으로" |
| ② | 전환 장면 "손발 → 조종"(T03)이 끝났을 때 | 오전에 쓸 시간의 **5분의 4**를 넘겼는가 | 사다리 3단 중 "실습 05 콘솔판을 강사 시연으로, 수강생은 웹 화면판만" |
| ③ | 표지 "조종"(D05)에 닿았을 때 | 남은 시간이 약 25분보다 적은가 | 사다리 4단: 조종 구간을 **점심 뒤 첫 순서**로 |

## 3. 비상 사다리 (위에서부터 차례로)

| 단 | 무엇을 | 줄어드는 분 |
|---:|---|---:|
| 1 | 건너뛰기 · 축약: V02(FAISS · Chroma · Milvus) 건너뛰기, S02 · G00 · S14 · S29 · S17의 말 줄이기, V01 축약 | 약 7.5 |
| 2 | 안내판의 생략 가능 소단계: 실습 03의 넷째 소단계, 실습 04의 "조각 크기 바꿔 보기" | 약 4 |
| 3 | 강사 시연으로 대체: 실습 04b 소단계 4(직접 조회), 실습 05 콘솔판 | 약 8 |
| 4 | 조종 구간(D05 ~ S21)을 점심 뒤 첫 순서로 | 약 18.5 |

- 3단의 효과가 스토리보드(약 11)보다 작은 이유: 실습 04b의 직접 조회를 시연으로 바꿔도 **셋째 열쇠(데이터 조회용 토큰)는 실습 05 전에 어차피 받아야** 한다. 발급 시간은 없어지지 않고 실습 05로 옮겨 갈 뿐이다.
- **3단을 쓸 때 반드시**: 실습 05를 시작하기 전에 "환경 파일의 셋째 열쇠 칸이 채워져 있는지"를 전원이 확인한다. 비어 있으면 그 자리에서 받는다(안내판 LAB05 노트 첫머리에도 같은 문장이 있다).
- 1~3단을 하나도 쓰지 않고 4단만 써도 오전은 맞는다. 곧 "장면과 실습을 줄이는 길"과 "조종 구간을 점심 뒤로 넘기는 길"은 서로 바꿔 쓸 수 있다. 4단을 쓰면 그만큼 오후 자유 실습이 줄어든다.

## 4. 4단을 쓸 때 바꿔 말할 문장

덱은 고치지 않는다. 말만 바꾼다.

| 장면 | 원래 흐름 | 4단을 쓸 때 |
|---|---|---|
| 손발 → 조종 전환(T03) 끝 | "다음은 두뇌가 손발을 조종하는 Agent입니다" | "두뇌가 손발을 조종하는 Agent는 점심 뒤 첫 순서로 보겠습니다. 오전에 만든 도구는 그대로 두세요" |
| 점심 안내(G03) | "오후는 Claude Code 연결 확인부터 시작합니다" | "오후는 Agent 실습을 먼저 하고, 이어서 Claude Code 연결로 갑니다" |
| 표지 "조종"(D05) | 오전 끝 무렵에 보여 줌 | 점심 뒤 첫 장으로 보여 주고 "오전의 손발에 조종을 더합니다"로 연다 |

## 5. 실습 전에 확인해 둘 준비물 (강사)

- [ ] 실습 02 · 03이 막힌 수강생에게 보여 줄 **준비된 출력**(안내판 "막히면" 칸이 이것을 가리킨다)
- [ ] 실습 04의 **저장 본문**(기사 접속이 안 될 때)
- [ ] 자유 실습용 **가상 CSV**
- [ ] 오후 시연 세 가지(사용 방향 ① ② ③)의 화면 또는 실시간 시연 준비
- [ ] 화면을 함께 볼 때 **환경 파일(열쇠가 든 파일)은 열지 않는다**는 안내. 실습 07의 요청문에도 "환경 파일은 열지 마세요"를 넣는다
- [ ] 일일 한도: 남은 한도를 사내 모델 운영 페이지에서 확인하는 방법 안내

## 6. 첫 회차를 마친 뒤 적어 둘 것

1. 실습 01에 실제로 걸린 시간과, 막힌 사람이 가장 많았던 단계.
2. 점검 지점 ① ② ③의 실제 시각.
3. 사다리를 몇 단까지 썼는가, 다음 회차에 미리 빼 둘 장면.
