- 핵심 메시지(1문장): 모델은 도구 이름과 넣을 값을 담아 호출을 요청하고, 실행은 프로그램이 합니다.

  - 한 줄 요지(`.thesis`): 모델은 도구 이름과 넣을 값을 담아 호출을 요청하고, 실행은 프로그램이 합니다.
  - 설명문(`.explain`, 한 문장): 프로그램이 도구의 이름·설명·입력 형식을 알려 주면, 모델은 어느 도구를 어떤 값으로 부를지 담은 호출 요청을 돌려줍니다.
  - 네 카드

    | 카드 | 위 라벨(`.panel-title`) | 본문(`.step-body`) | 작은 줄(`.step-desc`) |
    |---|---|---|---|
    | ① | ① 프로그램 | 도구 쥐여 주기 | 이름·설명·입력 형식 |
    | ② | ② 모델 | 호출 요청(tool_calls) | 도구 이름과 넣을 값 |
    | ③ | ③ 프로그램 | 실행과 결과 전달(ToolMessage) | 결과를 메시지 목록에 붙임 |

  - 계산 예시 띠(앞에 `.concept-badge` "개념 예시 · (13 + 29) × 10 ÷ 5"): 한 바퀴 · 더하기(13, 29) = 42 → 두 바퀴 · 곱하기(42, 10) = 420 → 세 바퀴 · 나누기(420, 5) = 84 → 답변

  - 코드 카드(개념 예시 · 교육용 가상 이름, 다섯 줄)

    ```python
    @tool  # ⓐ 함수를 도구로 · 교육용 가상 함수
    def divide_numbers(a: float, b: float) -> float:  # ⓑ 넣을 값 두 개
        """a를 b로 나눈 값을 돌려줍니다."""  # ⓒ 모델이 읽는 설명서
        return a / b
    model_with_tools = model.bind_tools(calc_tools)  # 카드 ① 도구 쥐여 주기
    ```
