# 사내 Claude 확인 요청서 · 실습 코드 사실 확인 (handoff-inhouse-claude-lab-check)

작성일: 2026-09-18 · 관련 문서: `ROADMAP2.md` 0절(확정 사실표), `docs/ai-agent-guide-실습자료-강의흐름요약.md`

사외에서 발표자료를 설계하고 있지만 실습 코드는 사내에만 있다. 코드를 봐야만 풀리는 질문을 여기에 모았다. **이 문서를 사내 Claude Code에 읽히고, 실습 폴더를 분석시켜 아래 답안 양식을 채운다.**

## 0. 답할 때 지킬 규칙 (사내 Claude에게)

- 방향은 한쪽이다. **사내 자료는 밖으로 내보내지 않는다.** 답안에는 코드 · 주소 · 키 · 모델명 · 테이블명 · 컬럼명 · 실제 장비 ID · 사람 이름을 **옮겨 적지 않는다.**
- 답은 **보기 기호(가/나/다…)와 개념 수준의 한 줄**로만 쓴다. 예: "나 — 조회 결과를 세션에 저장해 목록으로 보여 주고, 다음 답변에는 쓰지 않음".
- 숫자는 설정값(예: 조각 크기, 반복 상한, 검색 개수)만 적는다. 데이터 값은 적지 않는다.
- 확신이 없으면 "불확실 — 이유 한 줄"로 적는다. 추측으로 메우지 않는다.
- 코드를 고치지 않는다. 읽고 답하기만 한다.

## 2-1. 밤사이(2026-09-18) 메인 에이전트가 대신 내린 의사결정 이력

사용자가 자리를 비운 동안 "의사결정 권한은 메인 에이전트에게 있다"는 위임에 따라 내린 결정이다. 각 결정은 **메모리와 사실 자료를 근거로** 했고, 아침에 뒤집고 싶으면 "되돌리는 방법" 칸을 보면 된다. 사내 코드 확인이 있어야 최종 확정되는 결정은 ★로 표시하고 1절의 문항 번호를 적었다.

| 번호 | 결정 | 근거 | 되돌리는 방법 |
