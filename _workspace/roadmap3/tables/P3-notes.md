### 0-1. Agent 루프의 정의 문장 — 낱말 교체가 아니라 다시 쓴 문장

| 자리 | 문장 |
|---|---|
| **기준 정의(노트용, 긴 형)** | `모델이 결과를 보고 다음 도구 호출을 정하는 반복이 Agent 루프입니다` |
| 화면 한 줄 요지(짧은 형) | `모델이 결과를 보고 호출을 정하는 Agent 루프입니다` |
| 끝나는 조건(X-1 고정) | `호출 요청이 없으면 끝납니다` — 그대로 둔다 |
| 사이클 낱말(X-1 고정) | `판단 → 행동 → 관찰` — 그대로 둔다 |

- 폐기 문장: "두뇌가 손발을 조종하는 것이 Agent입니다" 계열은 **모두 삭제**했다(T03 화면·노트, N03 화면·노트, S17 노트, S21 노트, S22 화면·노트, D05 노트, D06 노트 = 8곳).
- 삭제하고 대체하지 않은 곳이 있다. N03·S17은 앞뒤 문장이 이미 같은 말을 하고 있어 정의 문장을 **지우기만** 했다(한 줄 요지 "한 번 묻고 답하면 LLM 호출이고, 결과를 보고 다시 판단하기를 되풀이하면 Agent입니다"가 정의를 대신한다).

### T03 · 제목 `손발에서 조종으로` → **`Tool 호출에서 Agent 루프로`**

- **바꾼 것** — 한 줄 요지를 "Tool은 두뇌의 손발입니다. 다음은 두뇌가 그 손발을 조종합니다."에서 "다음은 모델이 결과를 보고 호출을 정하는 Agent 루프입니다."로. ② 열 머리 `조종은 아직` → `Agent 루프는 아직`. ② 열 항목 `실제 데이터를 읽는 손발` → `…도구`. 아래 칩 `손발 · 실습 04b` → `Tool · 실습 04b`, `조종 · 실습 05` → `Agent · 실습 05`. alt 4건.
- **지운 것** — 설명문 꼬리 "실제 데이터를 읽는 손발 · 멈춤 장치 · 화면을 더합니다"의 `실제 데이터를 읽는`과 `거기에`(−11자). ③ 열이 이미 "멈춤 장치와 화면 더하기"를 말하고 ② 열이 "실제 데이터를 읽는 도구"를 말하므로 설명문이 도식을 되풀이했다. 노트의 "Tool은 두뇌의 손발입니다."와 '손으로' 풀이 두 문장(−45자).
- **지키지 않은 것 없음** — 세 열 구조(지금 되는 것 / 아직 안 되는 것 / 그래서 다음) 유지, 확인 질문("다음에 어느 도구를 부를지 정한 것은 코드였을까요, 모델이었을까요?")과 답 유지, R2-14 구분 문장 유지, 출처 줄 유지.
- **글자 수** — 화면 약 −1자(제목 +3, 요지 −1, 설명문 −11, 머리·칩 +8). 노트 약 −60자.
- **확인 필요** — ② 열 머리 `Agent 루프는 아직`이 두 줄로 접히면 `Agent는 아직`으로 줄인다.
