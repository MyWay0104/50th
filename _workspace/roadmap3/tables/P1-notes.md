## 1. 적용 시 주의 (오케스트레이터용)

1. **D01 · D02의 제목은 `title` 필드로 바꿀 수 없다.** `apply_table.py`의 `TITLE_RES`는 `<h1 class="hero-title">`만 찾는데 구간 표지의 실제 마크업은 `<h1 class="hero-title is-section">`이라 정규식이 맞지 않는다. 그래서 두 장면은 `replace`(screen)로 `<h1>` 안의 `<span class="nowrap">…</span>` 두 개를 한 개로 바꾼다. 다른 묶음의 구간 표지(D03~D07)도 같은 방식이어야 한다.
2. G01 · D01 · D02의 진행 띠는 `<li>` 단위로 바꾼다. `alt="열쇠 아이콘"`처럼 한 장면에 여러 번 나오는 문자열이 있어 `old`에 앞뒤 마크업을 붙여 유일하게 만들었다. **`old`를 줄이지 말 것.**
3. 아이콘 파일(`brain` `book-open` `hand` `joystick` `laptop` `rocket` `key` `door-open`)은 그대로 두고 `alt` 글자만 바꿨다(ROADMAP3 2-2). `alt`도 화면 텍스트이므로 6절 검증(비유 낱말 잔존 0건)에 걸린다.
4. 새 글에 인라인 `style` · hex 색 · `<br>` 을 쓰지 않았다. `--kind copy` 로 적용한다.

### 3-3. 되풀이해서 쓰는 정의 문장
- LLM: **`LLM은 텍스트를 생성할 뿐, 외부 데이터 조회나 계산은 하지 못합니다.`** (S04의 한 줄 요지. 뒤 구간에서 Tool의 필요를 말할 때 같은 표현을 쓴다)
- RAG: **`검색한 자료를 근거로 답합니다.`** (T01 띠 부연. S10의 정식 정의 `검색 증강 생성(RAG)은 …`과 충돌하지 않게 짧은 쪽만 반복)
- 문장 속 대체어: `두뇌` → **`모델`**(주어일 때) 또는 **`LLM`**(용어를 짚을 때). `손발` → **`도구`**/`Tool`. `조종` → **`반복 판단`**/`Agent 루프`. `책을 찾아보며 답하기` → **`검색해 근거로 답하기`**. `내 PC의 에이전트` → **`Coding Agent`**.

### 3-4. 한글 병기 위치 (중복 금지)

## 4. 확인 필요 사항

1. **[UI] G01 진행 띠의 부제 길이** — `dg-sub`를 `답 생성` · `자료 검색` · `도구 호출` · `반복 판단`으로 바꾸면서 칸마다 한글 2~3자가 늘었다. 7칸이 1920px를 나눠 쓰는 컴포넌트라 넘칠 수 있다. 넘치면 부제를 지우고 `axis-label`만 남기는 것이 다음 순서다(부제는 삭제 금지 항목이 아니다). → `slide_ui_designer` 판단.
2. **[UI] D02 표지의 제목이 `LLM` 세 글자** — 사용자 승인 사항이지만, 표지 7장 사이의 시각 균형(제목 길이 3자~10자)은 확인이 필요하다. 필요하면 `hero-sub`(`실습 02 · 실습 03`)의 비중을 키우는 쪽을 권한다. 글자를 더 붙이는 안은 사용자 지시(한 낱말)와 어긋난다.
3. **[UI] D01 · D02 제목의 `nowrap`** — 두 개였던 `<span class="nowrap">`을 하나로 합쳤다. `개발 환경과 인증 키`가 한 줄에 들어가는지 스냅샷으로 확인할 것.
4. **[내용] `데이터 조회용 액세스 토큰` / `데이터 조회용 토큰` 두 표기 병행** — E01의 키 지도(정의 자리)에서만 `액세스 토큰`, 나머지(LAB01 칩 등)는 `토큰`으로 줄였다. 한 가지로 통일하라는 판단이 서면 `llm-professional` 검증 단계에서 정해 주기 바란다. ROADMAP3 2-5는 두 표기를 모두 쓰고 있다.
5. **[내용] `정거장` → `단계`** — ROADMAP3 2-5 사전은 `학습 단계`로 적었지만, 화면·노트에서 `여섯 학습 단계`는 길고 어색해 **`단계`**로 줄여 썼다(`오늘의 여섯 단계`, `단계 아래 번호는`, `다음 단계는 RAG입니다`). 다른 묶음도 같은 선택을 하는 것이 좋겠다.
6. **[내용] T01 소제목 `실습 04 · 검색 후 답변`** — `찾아보며 답하기`(비유의 풀이)를 대체한 표현이다. 더 나은 안이 있으면 P2 묶음의 D03·S10 표현과 맞춰 주기 바란다.
7. **[적용] D01 · D02는 `title` 필드를 쓰지 않았다** — 1절 1항 참고. `--dry` 실행 결과에 "제목 요소가 없다"가 뜨지 않아야 정상이다.
