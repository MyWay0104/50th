## 0. 세로 여유를 어떻게 쟀나

측정표의 "하 48" 은 모든 장면에서 `.deck-footer`(absolute · bottom 48px)라 본문 여유가 아니다.
본문의 실제 여유는 **마지막 내용의 밑변**과 **`.source` 상자 윗변**의 차이다.

- `.source` 는 `margin-top:auto` 라 내용상자 밑변(y=952)에 붙는다. 높이 = padding-top 24 + 28px×1.4 ≈ 63px → 윗변 ≈ y 889~896.
- 출처 줄이 없는 장면(LAB02 · LAB03 · G03)은 y=952 가 그대로 밑변이다.
