Coding Agent의 작동 방식

모델에 도구를 붙인 점은 같고, 대상이 프로젝트로 넓어지며 관찰·판단·행동을 반복합니다.

Claude Code는 모델에 파일·명령 도구를 붙여 관찰→판단→행동을 반복하는 Coding Agent입니다. 오후에는 이 흐름으로 오전에 만든 장비 조회 챗봇을 읽고, 시연과 선택 과제의 대상으로 씁니다. 다른 도구보다 항상 낫다는 뜻은 아닙니다.

Claude Code는 모델 자체가 아니라, 모델에 파일 읽기·수정·명령 실행 도구와 실행 환경을 붙여 프로젝트 자체를 다루는 프로그램입니다. 오른쪽 열의 그림처럼 파일과 실행 결과를 관찰하고, 모델이 다음 행동을 판단하고, 도구로 행동한 뒤 그 결과를 다시 관찰하는 반복이 핵심이며, 도구를 더 부를 일이 없으면 멈추는 것도 오전 루프와 같습니다. 이 흐름을 한 번에 이어갈 수 있어서 이번 실습에 쓰는 것이고, 다른 도구보다 항상 낫다는 뜻은 아닙니다. 오전 조회 도구와 지금 볼 파일 수정 도구의 공통점을 한 가지만 말해 주세요.
