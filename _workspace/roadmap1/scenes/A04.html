출처: Claude Code 문서 — Features overview · MCP · Subagents · Hooks

앞서 Claude Code의 Skill을 다룰 때 옆에 짧게 보여 드린 세 기능을 조금 더 풀어 보겠습니다. MCP는 외부 시스템의 도구와 자료를 Claude Code에 전달하는 연결 규약인데, MCP 칸의 작은 그림처럼 AI 앱 N개와 도구 M개를 하나하나 이으면 N×M개의 연결이 필요하지만, 같은 규약을 따르면 앱과 도구가 각자 한 번씩만 맞추면 되어 N+M으로 줄어든다는 발상이며, 이 그림은 그 발상을 옮겨 그린 개념도입니다. MCP 서버가 내놓는 것은 도구, 자료, 프롬프트 세 가지이고, 승인된 문서나 DB를 읽는 식으로 쓰되 기존 파일·명령 도구로 충분하면 추가하지 않아도 됩니다. Subagent는 예외 입력 점검이나 설정 위치 조사처럼 독립적인 하위 작업을 별도 맥락에서 맡기고 결과만 돌려받는 방식인데, 여러 개를 쓰면 비용과 조정 작업도 늘어납니다. Hook은 파일 수정 후 포맷처럼 정해진 시점에 설정된 동작을 실행하며, 명령을 실행하는 유형과 모델 판단을 쓰는 유형이 따로 있습니다. 세 기능은 상하위 단계가 아니라 서로 다른 역할이라 필요하면 함께 조합하고, 실제 설치와 권한 설정은 사내 가이드의 승인된 방법을 따릅니다. CLAUDE.md에 적은 지침은 모델이 읽는 안내일 뿐 권한을 강제하지 않는다는 점도 기억해 두세요.
