출처: Claude Code Best practices 문서

지금부터 자유 실습이고, 진행 단계 띠에서 강조된 첫 단계에서는 목표와 계획만 정합니다. 먼저 앞에서 쓴 요청문을 다시 읽고 입력과 결과물을 확정하며, 계획에 큰 기능이 들어 있으면 이번에 만들 부분만 남깁니다. 이어서 Claude Code로 관련 파일이나 자료를 먼저 살펴보게 하고 작업 순서와 완료 조건 두 가지 이상을 계획으로 받는데, 오후에 연습한 탐색·계획 단계를 그대로 쓰는 것입니다. 사내 DB에 쓰거나 외부로 보내는 작업처럼 되돌리기 어려운 일은 오늘 범위에 넣지 않는데, 파일 변경은 Git이나 사본으로 되돌릴 방법이 있지만, DB에 쓴 내용이나 외부로 보낸 자료는 되돌리지 못하기 때문입니다. 구현을 시작하기 전에 한 분만 계획을 소리 내어 읽어 주시면 범위를 같이 점검하겠습니다. 순회할 때는 설치·접속 문제와 과제 범위 문제를 나눠서 돕겠습니다.
