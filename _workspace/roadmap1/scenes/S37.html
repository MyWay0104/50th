출처: Claude Code Skills 문서

화면 왼쪽 세 파일 카드가 이 실습의 순서로, 원문을 읽고, 절차 파일을 확인해 실행하고, 결과 노트를 확인합니다. 먼저 준비된 짧은 원문을 읽고, 왜 이 자료를 골랐는지와 어디에 쓸지를 내 의견으로 적습니다. 다음으로 준비된 Skill의 절차 파일을 열어 무엇을 입력받고 어떤 노트를 만드는지 읽는데, 앞 장에서 본 것처럼 이름·설명 부분과 본문 절차 부분이 나뉘어 있는지도 확인해 보세요. 이어서 실행하고, 마지막으로 결과 노트에서 출처 연결, 내 의견, 미확인으로 표시된 내용이 서로 구분되는지 확인하며, Obsidian이 없어도 텍스트 파일로 똑같이 진행할 수 있습니다. Skill 실행이 안 되는 분은 실습 가이드에 있는 같은 절차를 요청문으로 붙여 넣어 실행하고, 결과 확인 단계에서 짝의 Skill 결과와 비교해 보세요. 결과가 비슷하다면 Skill이 모델을 바꾸는 것이 아니라 같은 절차를 불러 쓰는 것임을 확인한 셈입니다. Claude Code 환경이 아직 안 되는 분은 짝과 같은 화면으로 진행합니다.
