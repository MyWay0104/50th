Coding Agent의 작동 방식

모델에 도구를 붙인 점은 같고, 대상이 프로젝트로 넓어지며 관찰·판단·행동을 반복합니다.

Claude Code는 모델에 파일·명령 도구를 붙여 관찰→판단→행동을 반복하는 Coding Agent입니다. 오후에는 이 흐름으로 오전 앱을 고칩니다. 다른 도구보다 항상 낫다는 뜻은 아닙니다.

  • 결과: 근거를 붙인 답변

오전에 만든 기사·SQL 조회 앱이 이번 시간 Claude Code의 작업 대상이고, 이번 시간의 목표는 Claude Code 실행 환경을 확인하고 오전 앱에서 고칠 기능 하나의 목표·범위·완료 조건을 적는 것입니다. 오전엔 우리가 모델에 검색·조회 도구를 붙였고, 오후엔 이미 도구가 붙은 Claude Code에게 일을 맡깁니다. Claude Code는 모델 자체가 아니라, 모델에 파일 읽기·수정·명령 실행 도구와 실행 환경을 붙여 프로젝트 자체를 다루는 프로그램입니다. 오른쪽 열의 그림처럼 파일과 실행 결과를 관찰하고, 모델이 다음 행동을 판단하고, 도구로 행동한 뒤 그 결과를 다시 관찰하는 반복이 핵심입니다. Agent를 모델·도구·오케스트레이션 세 요소로 나눠 보면, 이 반복을 관리하는 부분이 오케스트레이션입니다. 이 흐름을 한 번에 이어갈 수 있어서 이번 실습에 쓰는 것이고, 다른 도구보다 항상 낫다는 뜻은 아닙니다. 오전 SQL 조회 도구와 지금 볼 파일 수정 도구의 공통점을 한 가지만 말해 주세요.
