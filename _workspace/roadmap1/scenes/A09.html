부록 · 하네스와 Deep Agents

하네스는 모델에 도구·기억·맥락을 묶는 실행 틀입니다.

Deep Agents는 LangGraph 위에 계획·파일·위임 등을 미리 묶은 하네스입니다. Claude Code도 구현은 다르지만 같은 역할의 실행 틀입니다. 짧은 도구 호출이면 create_agent로 충분합니다.

출처: LangChain Concepts(Agent harnesses: Deep Agents)

오후 실습에서 Claude Code가 파일을 읽고, 계획을 세우고, 명령을 실행하는 모습을 보셨는데, 이것은 모델 혼자 하는 일이 아니라 모델을 둘러싼 실행 틀이 해 주는 일이고, 이 틀을 하네스라고 부릅니다. 화면 왼쪽 그림처럼 하네스는 모델에 외부 기능을 부르는 Tools, 대화와 기록을 남기는 Memory, 지침과 규칙을 담는 Context를 묶습니다. Memory는 대화 중 상태를 저장하는 체크포인터와 대화를 넘어 남기는 저장소로 나뉘고, Context에는 모델 호출 앞뒤에서 로그를 남기거나 가드레일을 거는 미들웨어가 들어갑니다. Deep Agents는 LangGraph 위에 작업 계획 목록, 허용된 경로 안의 파일 도구, 긴 출력을 파일로 넘기는 오프로딩, 하위 작업 위임을 미리 묶어 둔 하네스이고, 오른쪽 코드는 그 설정의 인자 이름만 보여 주며 값은 생략했습니다. Claude Code도 하네스라고 했지만 LangGraph나 Deep Agents로 만든 것은 아니고, 모델을 둘러싼 실행 틀이라는 역할이 같다는 뜻입니다. 다음 장에서 볼 사내 배포 패키지 예시도 이런 구성으로 만든 참고 예시입니다. 다만 도구 몇 개를 짧게 호출하는 작업이라면 create_agent로 충분하고, 하네스 기능은 긴 작업, 파일 작업, 사람 승인 같은 요구가 생길 때 고르면 됩니다. 인자 이름은 설치 판본에 따라 달라질 수 있으니 공식 문서에서 확인하세요.
