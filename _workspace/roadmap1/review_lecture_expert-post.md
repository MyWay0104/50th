빌드 전 요청 중 실습 안내판 통합(8→5), 개념 칩, 신설 장면 참여 질문, "AI 없는 RAG"·"SQL Agent" 명칭 교정, Part Finder 재배치(S15 노트+C03), Dokmo→S43, C04 "검토 전" 한 줄, S21/S22 연결 문장은 모두 반영됐다. 삭제·이동된 장면을 가리키는 낡은 참조("앞 시간", "실습 6·7", "다음 장에서 Skill", "B1–B7", "공통 미니 과제")는 화면·노트 어디에도 남아 있지 않다. 13개 오해 표현도 잔존 0건이다.

## 2. 전수 확인 결과 (a)–(e)

- (a) 낡은 참조: "앞 시간", "실습 6", "실습 7", "다음 장에서 Skill", "B1–B7", "공통 미니 과제", "15분" — **0건**. "다음 장" 7회(S01→G01, G01→G00, S10→R01, S21→G03, S39→M01 2회, A09→A10)는 모두 현재 순서와 맞음. "실습 3에서 만든 조회 함수"(S20), "실습 5에서 한 읽기"(M01), "오전 마지막에 본 하네스"(C04), "오후에 본 작업 기록"(S43) 모두 대상 장면 존재. 유일한 흔적: C04 자리표시 ID가 `P-S34`(이전 장면 ID).
- (b) 실습 안내판 6장(S08·S13·S19·S20·S26·M01): 소단계 5/4/4/3/3/4, 개념 칩 소단계 수와 동일, 완료 조건 각 1, 막히면 대체 경로 각 1 이상 — **전부 충족**. S20 칩 "② 데이터"가 소단계 "장비 ID 입력"에 붙어 있으나 노트가 "조회 함수는 데이터"로 풀어 주므로 허용.
- (c) 신설 장면 참여 질문: E01·L01·R01·C01·C02·C04·G03(준비물 지시)·M01(예측 먼저) — 있음. **C03만 없음**(사례 설명으로 끝남).
- (d) 오해 표현 13개: 잔존 **0건**. 반대로 교정 문구가 해당 장면에 모두 들어 있음(1→S04 노트, 2·3→A01, 4→S07, 5→S10, 6→S13 노트, 7→S17, 8→A03, 9·10→S23, 11→A04, 12→S30, 13→G00).
- (e) 교정 대상 명칭: "AI 없는 RAG" 0건(S13 노트는 "AI 없이 찾아서 읽기만"으로 RAG라 부르지 않음), "URL 요약=RAG" 0건("외부 문서 기반 요약 … 비로소 RAG"), "SQL Agent"는 **출처 줄에만 3회**(S15·S19·A06 "LangChain SQL Agent 가이드"). 공식 문서 제목이라 하우스 룰 위반은 아니지만, S19 화면이 "Text-to-SQL이 아니라 정해진 쿼리"라고 적은 바로 아래에 "SQL Agent 가이드"가 보이는 것은 수강생에게 혼선을 줄 수 있음(아래 선택 요청).
