- **S17 노트 "Workflow에 가깝습니다"** — 실습 3 코드가 create_agent류(모델이 반복 판단)라면 0-1절대로 "가장 작은 Agent"로 바꿈. 현재 문구는 인자 없는 도구 하나라는 결정 7에는 맞음.
- **C04 화면·노트 "공정 Engineer 1개월차"** — 강사 본인 사례인지 가상의 신입 사례인지 화면만으로 알 수 없음. 본인 사례면 "제가 공정 Engineer 1개월차에", 가상이면 "예: 공정 Engineer 1개월차가"로 구분 필요. 강사 확인.
- **S01 "NAND Implant기술 이상우 TL" vs S02 "NAND Implant 공정 Engineer"** — 부서명과 직무 표현이 달라 보이는데 둘 다 맞는 표기인지 강사 확인. S01의 "Implant기술" 띄어쓰기도 함께.
- **G00 출처 줄의 YouTube 링크와 S22 출처의 "Kaggle Agents 백서"** — 하우스 룰 "출처 줄은 공식 문서와 논문만"에 엄격히 대면 둘 다 예외. G00은 학습 철학의 출처로 사용자가 의도한 것이라 유지 여부만 확인. G00 노트 "링크는 실습 가이드 후속 읽을거리에 있으니"도 실습 가이드에 실제로 실렸는지 확인.
- **캡처 자리표시 12곳**(P-S02·S08·S13·S19·S20·S26·S29·C02·S28·C04 등) — 확보 계획은 사용자 몫. 현재 대체 문구로 진행 가능.
- **FAISS 점수 종류** — 화면에 없고 R01 노트가 실습 가이드로 위임해 현 문구로 안전.
