## 교안 연계 문장 판단 (알려진 불일치)

**권고: 부록 담당 방식(삭제·중립화)으로 통일합니다. B1–B7 노트의 교안 문장 22곳도 같은 기준으로 고칩니다.**

1. 발표자 노트는 강사가 소리 내어 읽는 대본입니다. "교안 4일 과정에서…", "LLM 활용과 고급화 과정 교안 1장에서 더 자세히…"를 말하면 수강생은 받지 않은 자료를 안내받게 됩니다. 사용자 요청 9("수강생이 모르는 자료")에 정면으로 걸립니다.
2. 이 문장들은 대부분 출처를 밝히는 역할입니다. 화면 출처 줄에서 교안을 이미 지웠으므로, 노트에만 남기면 화면과 노트가 어긋납니다.
3. 부록은 이미 지웠고, G02 노트는 부록을 "교안 내용을 옮겨 둔 부록"이라고 소개합니다. 한쪽만 남기면 앞뒤 설명이 서로 맞지 않습니다.
4. 처리 원칙은 두 가지입니다. 문장에 내용이 있으면(S10 세분 단계, S16 메시지 이름, S17 다섯 패턴, S22 세 요소, S34 메모리 세 유형, S36 점진적 공개·N+M) 내용은 남기고 출처 표현만 지우거나 공식 문서 쪽으로 돌립니다. "더 자세히 다룹니다"처럼 안내만 하는 문장은 부록이 있으면 부록 장면으로 바꾸고, 없으면 지웁니다.
5. 강사 본인은 필요하면 교안 연계를 별도 강사용 메모로 가지고 있으면 됩니다(발표자 노트 밖).

## 보류 (사용자 확인)

1. **G00 YouTube 출처 줄**(`출처: YouTube · AgentOS 채널 · URL`): 공식 문서가 아니지만, 화면에 영상 제목·썸네일을 보여 주므로 출처 표기가 필요합니다. 강사 권고는 유지입니다. 사용자 요청 9의 '공식 문서만'에 예외로 둘지 확인이 필요합니다.
2. **A10 오른쪽 화면(사내 배포 패키지 승인 카드)**: 원 출처인 현업 활용 가이드를 수강생이 볼 수 있는 자료인지 확인이 필요합니다. 볼 수 없는 자료라면 이미지를 개념 예시 도식으로 바꾸는 편이 요청 9에 맞습니다(B-04는 노트 문구만 고침).
3. **논문·백서 출처 유지**: Vaswani 2017, Ouyang 2022, Lewis 2020, Kaggle Agents 백서는 공개 1차 자료라 유지를 권고합니다. '공식 문서' 범위에 포함하는지 사용자 확인이 필요합니다.
4. **실습 안내판 세부**(S08·S13·S19·S26·S32·S37·S41–S43): 시간을 지운 뒤 머리 줄이 '실습 가이드 해당 장' 하나만 남고, S08은 아래 '코드 위치 … — 실습 가이드 해당 장'과 겹칩니다. 사용자가 사내 실습 HTML에 맞춰 다시 고칠 예정이므로 이번에는 손대지 않습니다. S41–S43 진행 띠 7칸(계획→구현→첫 실행→기능 멈춤→검증→공유→종료)과 제목 '1·2·3단계'의 대응은 적용 뒤 스크린샷 시각 검토에서 확인합니다.
5. **A08 출처 문서의 정확한 이름**: LangGraph 공식 문서의 Agentic RAG 페이지 제목을 확인한 뒤 B-17에 넣습니다. 추정해서 적지 않습니다.
