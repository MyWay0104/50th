## 보류 (사용자·도구 확인 필요)

- **장면당 이미지·인포그래픽 규칙**: 세 전환 장은 아이콘 붙은 카드 3열과 화살표 띠만 있고 그림·캡처가 없다. `qa_rules.py`가 compare 카드를 인포그래픽으로 인정하는지 실행 결과가 없어 판정하지 못했다. 미인정이면 T 장면에 작은 흐름 그림(실습 N → N+1)을 띠 대신 넣어야 한다.
- **실습 1 ⑤의 실제 결과**: 사내 모델이 최신 자료 질문에 "모른다"고 답하는 비율이 높으면 T01 ② 열 "출처를 대며 답하기"보다 "학습 이후 자료"가 주된 관찰이 된다. 수정 요청의 T01 노트 문구는 두 경우를 모두 담았으므로 사용자가 사내 모델로 한 번 돌려 본 뒤 강조점을 정한다.
- **T02 참여 질문 교체안의 전제**: "기사 백 편을 붙이면 건수를 셀 수 있나"는 실습 2가 기사 한 편 통째 요약이라는 현재 판본 기준이다. 실습 가이드가 여러 기사 검색 구성으로 바뀌면 질문을 다시 맞춘다.
- **S21 설명문 축약 시 운영 안내 위치**: "Claude Code 모델 연결은 오전 API와 별개"를 화면에서 빼도 되는지는 사내 환경 안내 의무에 달렸다. 화면에 남겨야 한다면 S21이 아니라 G03(점심) 준비물 줄에 두는 편이 전환 메시지를 해치지 않는다.
