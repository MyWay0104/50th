- 빌드 메모: 오케스트레이터가 부제 위치로 확정하면 `.panel-title`을 빼고 `p.scene-subtitle`을 `board-meta` 뒤에 둔다. 그러면 가용 높이가 506px로 줄어도 좌측 450px는 들어가지만, 글자 크기는 5종이 된다. 어느 쪽이든 대체 과제 문구를 노트로 옮길 필요는 없다(1줄로 들어감).

## S33 · 다른 입력으로 재확인

- data-skill: `title-bullets` · section 클래스: `scene clip`
- 배치 순서: eyebrow → 제목 → `p.scene-subtitle` → `.stack` [ `ul.bullets`(3개) → `.callout` ] → `.source` (B4 S27과 같은 구조 + 부제)
- 요소 ↔ 문구
  - 제목: 다른 입력으로 재확인
  - `.scene-subtitle`: 실행 전에 예상 결과를 먼저 말하기
  - `li` 1: `<strong>기존 정상 입력</strong>` 이전과 같은 결과인가
  - `li` 2: `<strong>새 기능 입력</strong>` 예상한 안내가 나오나
  - `li` 3: `<strong>설명</strong>` 바꾼 코드가 하는 일을 한 문장으로
  - `.callout`: "확인하지 못한 입력은 " + `<strong>미확인</strong>` + "으로 적어 둔다"
  - `.source`: 근거: 강사 Python 교육 진행 규칙(예측·실행·설명·입력 변형)
- 강조: bullets strong 3개(확인 대상 이름, 한 묶음) + callout strong "미확인" = 2묶음.
- 글자 크기: 72 / 44 / 34 (3종)
- 넘침 근거
  - 폭: bullets 1,508px. 최장 li 3 ≈ 한글 16×44 + 공백 6×13 = 782px → 1줄. 부제 ≈ 한글 14×34 + 공백 50 = 526px → 1줄. callout ≈ 774 + 72 = 846px → 1줄
  - 높이: 145 + 부제 64 + 56 + bullets 242 + 24 + 104 + 58 = **693px ≤ 872**
- 플레이스홀더: 없음
- 빌드 메모: S27과 bullets·callout 구조를 같게 두어 B4·B5의 마무리 확인 장면이 같은 모양으로 보이게 한다. 수치를 넣지 않는다.
