      <div class="dg-box accent" data-editable="true">설명<span class="dg-sub">바꾼 코드를 한 문장으로</span></div>
    </div>

  </div>

- 요지: 실행 전에 결과를 먼저 말하고, 다르면 그것이 단서다
- 설명: 옆 사람이 골라 준 입력 하나로 실행 전에 결과를 예상해 말한다. 예상과 다른 결과는 실패가 아니라 바꾼 코드의 동작 조건을 알려 주는 단서다.
- 출처: 근거: 강사 Python 교육 진행 규칙(예측·실행·설명·입력 변형)

- 가로: 3칸 = (1,680 − 4×20 − 2×40)/3 = 507, 안쪽 약 457px. 보조 최장 "기존은 그대로? 새 입력은 안내?" 약 299px → 1줄. 캡션 약 330px → 1줄. callout = 한글 24×34 + 칩 약 122 + 공백 약 90 + 패딩 72 = 약 1,100px < 1,680 → 1줄.
- 강조: `.dg-box.accent`("설명") 한 곳. B5에서 새로 요구하는 행동이다. "미확인" 칩은 기본 `.chip`(흰 바탕·헤어라인)이다. 문구 파일은 "회색 칩"이라고 적었지만, 흰 칩이 파랑 틴트 띠 위에서 회색 테두리 상자로 보이므로 새 클래스를 만들지 않는다. callout에는 strong이 없다(v0.3의 strong "미확인"을 칩이 대신한다).
- 칩 편집 단위: callout 전체에 `data-editable`을 붙이지 않고, 앞 문장 span · 칩 · 뒤 문장 span에 따로 붙인다. "미확인" 칩 뒤에는 공백 없이 "으로"를 붙인다.
- 글자 크기: 72 / 40 / 34(callout) / 32(설명·상자) / 28(칩). 5종이다(34·32는 같은 문장층).
- 주의점

  - 수치를 넣지 않는다. 마지막 노트 문장 "15시 20분에는…"으로 B6과 이어진다(화면 문구 아님).
