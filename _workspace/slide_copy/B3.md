  3. [프로그램] 실행과 반환 — 실제 함수·SQL을 실행 (`is-accent`)

- 보조 문장(callout): 모델은 함수를 직접 실행하지 않는다 · @tool은 설명과 입력 형식을 만든다
- 출처: LangChain Tools 문서 · OpenAI Function calling 가이드
- 발표자 노트: "모델이 도구를 쓴다"는 말은 모델이 Python 함수를 자기 안에서 실행한다는 뜻이 아닙니다. 프로그램이 먼저 도구의 이름, 설명, 입력 형식을 알려 주면, 모델은 어떤 도구를 어떤 인자로 부를지 요청만 합니다. 실제 함수나 SQL은 프로그램이 실행하고, 그 결과를 모델에게 돌려주면 모델이 답하거나 다음 도구를 요청합니다. @tool은 함수 정보로 도구 설명과 입력 형식을 만드는 데 쓰입니다. 화면의 도구 호출 기록은 요청과 결과일 뿐, 모델의 생각 전체를 보여 주는 것은 아닙니다.
- 체크리스트 대조: 3번 관련. 4단계의 "다음 도구를 요청"은 가능성으로만 두고, 스크립트·Workflow·Agent 구분은 S17에서 설명. 13번: 예시 도구명은 가상 이름. 초안 "모델의 도구 호출 요청"을 "호출 요청 — 도구 이름과 인자를 반환"으로 바꿔 실행 주체를 분명히 함.
