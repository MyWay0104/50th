출처: Claude Code 공식 문서 Overview

방금 실행해 본 Claude Code를 오늘은 세 방향으로 나눠 봅니다. 첫째는 코드를 짜려는 것이 아니라 Agent 그 자체로 쓰는 방향으로, 내 PC의 CSV 같은 파일을 읽어 집계하고 요약하게 하는 것입니다. 둘째는 원래 목적인 coding agent로, 엑셀 두 파일을 비교하는 스크립트나 부품 검색 도구처럼 작은 프로그램을 만드는 방향입니다. 셋째는 Obsidian 같은 노트 앱과 붙여 자료와 내 판단을 쌓고, 그 기록을 읽는 나만의 Agent로 키워 가는 방향입니다. 세 방향 모두 도구는 같고, 카드 아래 한 줄처럼 오전에 본 원칙, 곧 계산은 코드가 하고 완료 조건을 먼저 정하며 AI가 만든 정리는 검토가 필요하다는 것이 그대로 이어집니다. 내 업무에 가장 먼저 쓸 방향은 어느 쪽일지 손가락으로 1, 2, 3 중 하나를 들어 주세요. 이어서 방향 하나씩 시연 화면과 함께 보겠습니다.
