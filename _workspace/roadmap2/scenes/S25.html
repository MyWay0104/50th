출처: Claude Code 공식 문서 Best practices

"챗봇 개선해줘"라고만 하면 Claude Code는 무엇을 어디까지 바꿀지 스스로 추측해야 하고, 우리도 결과를 받았을 때 끝난 것인지 판단할 기준이 없습니다. 아래 여섯 칸처럼 목표, 입력과 출력, 바꿀 범위, 지켜야 할 제약에 더해 어떤 입력에서 어떤 결과가 나오면 끝인지를 적으면 작업 방향과 확인 방법이 함께 정해지고, 공식 모범사례도 확인할 수 있는 기준을 요청에 함께 주라고 권합니다. 예시는 오전에 만든 장비 조회 챗봇에 없는 장비 ID 안내를 붙이는 요청문입니다. 특히 주황 칸의 완료 조건처럼 기존 질문의 결과가 그대로여야 한다는 조건을 넣어 두면, 새 기능을 붙이다 원래 기능을 망가뜨렸는지 확인할 수 있습니다. 오류 없이 실행되는 것, 결과가 정확한 것, 사용자의 목적에 맞는 것은 각각 따로 확인할 대상입니다. 이제 오전 챗봇에 붙이고 싶은 기능 하나의 완료 조건을 "어떤 입력에서 무엇이 나오면 끝"이라는 한 문장으로 적어 보세요. 이 문장이 자유 실습이나 선택 과제의 입력이 되니, 두 분 정도 읽어 보겠습니다.
