도구의 한계와 화면

도구까지 붙인 함수는 코드를 아는 사람만 쓰므로, 다음은 누구나 쓰는 화면입니다.

실습 3에서 질문을 넣으면 모델이 조회 도구를 부르고 결과를 문장으로 설명하는 것까지 확인했습니다. 그러나 이 함수는 코드를 열어 실행할 줄 아는 사람만 쓸 수 있으므로, 다음 실습은 입력 칸과 결과 화면을 붙여 코드를 모르는 동료도 쓰게 합니다.

실습 3 · 도구

출처: Streamlit Architecture 문서

실습 3에서 도구가 필요 없는 질문에 도구 호출 기록이 비었던 장면을 떠올려 보세요. 그런데 이 함수는 노트북을 열고 코드를 실행할 줄 아는 사람만 쓸 수 있고, 입력 칸도 결과 화면도 결과가 없을 때의 안내도 없습니다. 다음 실습은 같은 조회 함수를 그대로 두고 앞에 Streamlit 화면을 붙입니다. 장비 ID를 넣으면 위치와 진행 공정이 나오게 하고, 입력에서 함수를 거쳐 화면으로 이어지는 연결을 함께 짚습니다. 결과 없음 안내는 오늘 오전엔 붙이지 않고, 오후에 Claude Code에게 맡겨 볼 항목으로 남겨 둡니다. 여러분이 만든 조회 함수를 옆 팀에 주려면 무엇이 더 필요할까요, 한 분만 말씀해 주세요. 오후 구간에서는 바로 이 앱을 Claude Code가 읽고 고치므로, 오전에 만든 화면이 오후의 재료가 됩니다. 다음 장에서는 실습 4의 화면 구조를 먼저 보겠습니다.
