# 마지막 검토 지시문 템플릿 (적용 뒤, 사용자 확인 직전)

세 갈래로 나눠 동시에 돌린다. 시각 검토 2개는 `general-purpose`, 내용 검토 1개는 `lecture_expert` 에게 준다.
스크린샷은 먼저 만들어 둔다: `npx hyperframes snapshot topics/{{topic}} --at {{시각 목록}} --no-end -o {{스냅샷 폴더}}`
(장면 N 은 `(N-1)×장면길이 + 1` 초쯤에서 찍힌다. 장면별로 한 장씩 필요하면 시각을 나열한다.)

---

## A. 시각 검토 (담당: {{시작 쪽}}–{{끝 쪽}})

너는 발표자료의 마지막 시각 검토를 맡는다. 스크린샷 `{{스냅샷 폴더}}/slide-NN.png` 를 한 장씩 모두 연다.

### 이 덱의 디자인 규칙 (결함으로 보지 않을 것)

{{테마·색·여백·자리표시 등 의도한 규칙을 적는다}}

### 볼 것

1. 정렬 이상(기준선 어긋남, 아이콘·로고 위치, 캡션과 그림 거리)
2. 치우침(한쪽에 몰리고 반대쪽이 크게 빔)
3. 글자(오탈자, 깨짐, 겹침, 잘림, 어색한 줄바꿈, 한 낱말만 다음 줄로 떨어짐)
4. 가독성(강의실 뒤에서 읽히는 크기, 대비)
5. 하우스 룰 위반이 화면에 남았는지({{예: 시간 표기·반말·출처 표기}})
6. 일관성(같은 역할 요소가 장면마다 같은 자리·같은 크기)

### 출력

`{{출력 파일}}`

- 장면별 한 줄 판정: `NN쪽 · 통과` 또는 `NN쪽 · 수정 필요 — 요약`
- "## 수정 요청" 표: 번호 · 쪽 · 요소 · 현재 상태 · 제안(구체적으로) · 심각도(높음/중간/낮음)
- 끝에 "수정 필요: 높음 N · 중간 N · 낮음 N"

심각도 기준: 높음 = 잘림·겹침·깨짐·오탈자·요청 위반 / 중간 = 눈에 띄는 정렬 이상·큰 빈 공간·어색한 줄바꿈 / 낮음 = 미세 조정

## B. 내용 검토

너는 lecture_expert 다. 적용이 끝난 덱 전체를 한 번에 본다.

### 읽을 것

1. `{{추출본 경로}}` (`scripts/deck/dump_deck_text.py` 결과) — 주 자료
2. 비교가 필요할 때만 수정 전 추출본, 화면 모양이 필요할 때만 스크린샷

### 볼 것

1. 이번 수정 요청이 빠짐없이 반영됐는가(남은 곳을 쪽·문구로 적는다)
2. 말투 품질(존댓말 일관성, 어색한 문장, 너무 길어진 화면 문장)
3. 새 제목이 내용을 대표하는가
4. 잘못된 정보·교육 목적에 어긋나는 표현이 생기지 않았는가(사실 경계 표 기준)
5. 흐름 정합성(구간과 구간이 노트로 이어지는가, 마지막 장이 하루를 닫는가)
6. 화면과 노트의 어긋남(노트가 없는 요소나 옛 제목을 가리키는 곳)

### 출력

`{{출력 파일}}`

- "## 전체 판정" 5–8줄
- "## 수정 요청" 표: 번호 · 쪽(장면 ID) · 화면/노트 · 현재(정확한 문구) · 요청(정확한 새 문구) · 심각도 · 이유
- "## 보류(사용자·강사 확인)"
- 끝에 "수정 필요: 높음 N · 중간 N · 낮음 N"

## 공통

- 원본(`index.html` 등)은 고치지 않는다. 검토 파일만 쓴다.
- 사용 한도가 빠듯하면 5장(또는 한 묶음)마다 출력 파일에 중간 저장한다.
